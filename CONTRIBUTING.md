# Contribuyendo a Angel Whispers Masterclass

¡Gracias por tu interés en contribuir a Angel Whispers Masterclass! Este documento proporciona orientación y pautas para contribuir al proyecto.

## Cómo Contribuir

### 1. Reportar Bugs
Si encuentras un error, abre un issue con:
- **Descripción clara** del problema
- **Pasos para reproducir**
- **Navegador y dispositivo** donde ocurre
- **Capturas de pantalla** si es relevante

### 2. Sugerir Mejoras
¿Tienes una idea para mejorar el proyecto?
1. Abre un issue describiendo la mejora
2. Explica el caso de uso y beneficios
3. Espera feedback antes de comenzar a trabajar

### 3. Enviar Pull Requests
1. Fork el repositorio
2. Crea una rama para tu feature (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request

## Códigos de Conducta

Por favor, sé respetuoso y considerado con otros colaboradores. Cualquier comportamiento abusivo, discriminatorio o de acoso resultará en la exclusión del proyecto.

## Pruebas

Antes de enviar un PR:
1. Prueba en múltiples navegadores (Chrome, Firefox, Safari, Edge)
2. Prueba en dispositivos móviles
3. Verifica que no haya errores en la consola

## Documentación

Si agregas una feature:
1. Actualiza el README.md si es necesario
2. Documenta los cambios en comentarios claros
3. Actualiza el changelog si corresponde
